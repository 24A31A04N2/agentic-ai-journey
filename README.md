## 🧭 Design Principles (v5)

- **Durability-First:** Every skill ranked by durability tier. Tier 1 (system design, debugging, security) gets the most time.
- **Security Early:** Prompt security starts Day 20, not Day 151.
- **Evaluation Built-In:** Evaluation fundamentals from Day 21; every project from Phase 3+ requires measurable metrics.
- **3 Deep Flagship Projects:** Not 8 scattered projects — 3 production-grade systems with 13 mandatory deliverables each.
- **Framework-Independent Thinking:** Orchestration concepts first, framework APIs second.
- **AGI-Resilient:** If current frameworks, protocols, or models are replaced by dramatically better alternatives, these skills remain valuable.
